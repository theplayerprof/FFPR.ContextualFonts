# Changelog

## 1.0.10 — Initial public release

- Added configurable Classic, Modernized, Default, and inherited font selection for interface text throughout Final Fantasy I–VI Pixel Remaster.
- Added contextual categories for dialogue, menus, battle text, item and equipment descriptions, shops, and game-specific interfaces.
- Added targeted font fitting for selected menu and battle fields, especially numeric ones.
- Added optional TextProbe and Hierarchy diagnostics in a separate configuration file.
- Added automatic first-run configuration generation.
